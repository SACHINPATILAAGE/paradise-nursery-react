# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application. It allows users to browse different categories of plants, view plant information, add plants to a shopping cart, manage quantities, remove products, and view the total shopping cart amount.

## Features

- Paradise Nursery landing page
- Background image on the landing page
- Get Started button
- Navigation bar
- Home, Plants, and Cart navigation links
- Three plant categories
- Six unique plants in each category
- Plant thumbnails
- Plant names
- Plant prices
- Add to Cart functionality
- Disabled Add to Cart button after adding a product
- Dynamic cart item count
- Redux Toolkit state management
- Increase and decrease product quantity
- Delete products from cart
- Individual product totals
- Overall cart total
- Checkout button with Coming Soon message
- Continue Shopping button

## Technologies Used

- React
- JavaScript
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS

## Plant Categories

1. Indoor Plants
2. Succulents
3. Outdoor Plants

## Project Purpose

The project demonstrates the use of React components, React Router, Redux Toolkit, dynamic rendering, state management, and responsive CSS to create a functional e-commerce shopping experience.
